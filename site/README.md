```
│   ├── plush_pepe.png
│   ├── eternal_rose.png
│   ├── durov_cap.png
│   ├── mighty_arm.png
│   ├── heroic_helmet.png
│   └── scared_cat.png

```

## 🖼️ Добавление изображений NFT

Сайт настроен для использования реальных изображений NFT. Поместите изображения в папку `images/` со следующими именами:

1. **plush_pepe.png** - Plush Pepe (фиолетовый фон)
2. **eternal_rose.png** - Eternal Rose (черный фон)
3. **durov_cap.png** - Durov's Cap (серый фон)
4. **mighty_arm.png** - Mighty Arm (коричневый фон)
5. **heroic_helmet.png** - Heroic Helmet (фиолетовый фон)
6. **scared_cat.png** - Scared Cat (темный фон)

### Как получить изображения с оригинального сайта:

1. Откройте https://lumavouch.duckdns.org/ в браузере
2. Откройте инструменты разработчика (F12)
3. Найдите элементы `<img>` с атрибутом `src="data:image/png;base64,..."`
4. Скопируйте base64 данные и декодируйте их в изображения
5. Или просто кликните правой кнопкой на изображение → "Сохранить изображение как..."

### Альтернатива: использовать Python скрипт

Если у вас установлен Python с библиотеками `requests` и `beautifulsoup4`:

```bash
cd "c:\Users\admin\Desktop\Новая папка"
python download_images.py
```

## 🎨 Настройка цветов

Вы можете изменить цветовую схему в файле `style.css`, изменив переменные в `:root`:

```css
:root {
    --primary-color: #0088cc;      /* Основной цвет */
    --primary-dark: #006699;       /* Темный оттенок */
    --text-dark: #1a1a1a;          /* Цвет текста */
    --text-gray: #6b7280;          /* Серый текст */
    --bg-light: #f9fafb;           /* Светлый фон */
    --bg-white: #ffffff;           /* Белый фон */
    --border-color: #e5e7eb;       /* Цвет границ */
}
```

## 📝 Редактирование контента

Весь текстовый контент находится в `index.html`. Просто найдите нужный текст и измените его.

Например, чтобы изменить заголовок:
```html
<h1 class="hero-title">Надёжный гарант сделок с Telegram Gifts</h1>
```

## 🐛 Решение проблем

**Изображения не отображаются?**
- Проверьте, что файлы находятся в папке `site/images/`
- Проверьте, что имена файлов написаны правильно (с маленькой буквы, с подчеркиваниями)

**FAQ не открывается?**
- Убедитесь, что файл `script.js` находится в той же папке
- Проверьте консоль браузера (F12) на наличие ошибок

**Стили не применяются?**
- Проверьте, что файл `style.css` находится в той же папке что и `index.html`
- Попробуйте очистить кэш браузера (Ctrl+F5)
